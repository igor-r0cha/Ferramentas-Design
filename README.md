# Ferramentas-Design

Linha do Tempo sobre ferramentas de design, projeto desenvolvido para a matéria de Interação Humano Computador.

## 📜 Descrição

Este projeto é uma linha do tempo interativa que apresenta a evolução das ferramentas de design, desde a invenção da prensa de Gutenberg no século XV até as mais recentes tecnologias de inteligência artificial e realidade aumentada. A linha do tempo foi criada como um trabalho acadêmico para a disciplina de Interação Humano Computador, do 5º semestre do curso de Ciência da Computação.

## ✨ Funcionalidades

* **Linha do Tempo Interativa:** Navegue pela história do design de forma fluida e visualmente agradável.
* **Animações Dinâmicas:** Efeitos de transição e blur que destacam o item da linha do tempo em foco.
* **Background Dinâmico:** O plano de fundo da página se altera de acordo com a imagem do evento selecionado.
* **Índice de Navegação Rápida:** Um índice lateral permite navegar rapidamente para um ano específico na linha do tempo.
* **Design Responsivo:** A aplicação se adapta a diferentes tamanhos de tela, proporcionando uma boa experiência tanto em desktops quanto em dispositivos móveis.

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Para a estruturação do conteúdo.
* **CSS3:** Para a estilização e design da página.
* **JavaScript:** Para a interatividade e manipulação do DOM.
* **jQuery:** Para a simplificação do código JavaScript e manipulação de eventos.
* **GSAP (GreenSock Animation Platform):** Para a criação das animações avançadas da linha do tempo.

## 🚀 Como Visualizar

Para visualizar o projeto, basta abrir o arquivo `index.html` em seu navegador de preferência.
